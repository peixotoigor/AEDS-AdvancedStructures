# AEDS-AdvancedStructures

Projeto acadêmico para estudo, implementação e análise de um Fibonacci Heap.

## Objetivos

- Implementar soluções corretas e fáceis de compreender.
- Analisar complexidade de tempo e espaço.
- Comparar o Fibonacci Heap com uma fila de prioridade de referência quando
  aplicável.
- Registrar experimentos, resultados e limitações.

## Organização

```text
src/
  core/       Arquivos `.cpp` e ponto de entrada dos testes
  include/    Arquivos `.hpp` e interfaces públicas
benchmarks/   Medições de desempenho
docs/         Requisitos, arquitetura, estilo, desenvolvimento e validação
results/      Tabelas, dados e gráficos gerados
```

Consulte a documentação em [`docs/`](docs/) para detalhes sobre escopo,
organização e validação.

## Requisitos

- Compilador compatível com o padrão adotado pelo projeto.
- Ferramentas de build definidas pelos arquivos do repositório.
- Ferramentas adicionais somente quando descritas na documentação ou no
  código.
